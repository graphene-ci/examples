# AGENTS.md — examples

Компилируемые примеры текущего Go SDK Graphene. Они являются проверяемой
пользовательской поверхностью, а не эскизами будущего API.

## Правила

- Перед изменением прочитайте `../GRAPHENE.MD` и документацию SDK в `../docs`.
- Код, имена и комментарии — на английском; README — на русском.
- Коммиты — Conventional Commits, без `Co-Authored-By`.
- Каждый пример остаётся самостоятельным Go-модулем.
- `go run . plan` и `go test ./...` должны проходить в изменённом примере.
- Пример использует только уже существующую публичную поверхность зависимостей.
- Изменение показанного сценария одновременно обновляет `README.md` и
  соответствующую страницу в `../docs`.
